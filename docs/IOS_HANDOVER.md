## Why nothing needs copying from Windows

Every git-ignored file is either regenerated by the toolchain
(`GeneratedPluginRegistrant.*`, `local.properties`, `gradlew`,
`.flutter-plugins-dependencies`, `Pods/`) or is Windows/IDE-only
(`*.iml`, `.idea/`, `.claude/worktrees/`).

`run.ps1.txt` carries `SUPABASE_URL` and `SUPABASE_ANON_KEY` and is
committed, so the clone already has them. The anon key is a publishable key
— RLS is the actual access boundary, not its secrecy.

Do **not** copy `.claude/settings.local.json`. It is not needed to build, and
it holds a plaintext password that has never been rotated.
