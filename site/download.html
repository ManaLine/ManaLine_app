Download

MANA LINE is in testing. It isn't publicly available yet.

A build exists and is being worked from a real lending business's book today — but it hasn't been handed to anyone outside that testing. A wrong number on a collection screen is a mistake nobody notices, which is exactly the kind of mistake worth ruling out before the app reaches your phone.

Where things stand
Android

Play Store: not listed yet

MANA LINE runs on Android phones. The build is real; the Play Store listing that would let you install it from there is not published while testing continues.

Android app Coming soon

This turns into a real link once the listing is published — nothing else on this page changes.

iPhone

There is no iPhone version

MANA LINE does not run on iOS, and there is no iPhone build in progress. That is not the same statement as "coming soon" — if an iOS version is ever started, it will be announced here, not implied by a badge sitting greyed out in the meantime.
