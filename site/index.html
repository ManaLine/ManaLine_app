What the notebook could never do
The problem

Every lending business already keeps a ledger. It just isn't safe.

It is a notebook, or several — one for the owner, one carried by each agent on their route. A collection gets written down in pencil at the customer's door, copied later into the main book, and if the copying gets missed for a day, or a page gets torn, or the agent changes, there is no second copy to check it against.

At the end of the month somebody has to add it all up by hand, and the figure it produces is only as good as every page that led to it — there is no way to go back and reconstruct a week's collections once the page that recorded them is gone.

MANA LINE does not try to make the notebook nicer. It replaces the thing the notebook was for: one record of what every customer owes, updated the moment an agent collects it, that the owner and the agent are both looking at.
